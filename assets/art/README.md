# 그림 목록

게임은 `res://assets/art/<종류>/<id>.png`가 있으면 그림을, 없으면 임시 도형을 그린다(`src/ui/art.gd`). 그래서 아래 파일을 **이름 그대로** 하나씩 넣으면 그 자리만 바로 바뀐다. 다시 빌드할 필요는 있지만 코드는 고치지 않는다.

- 형식: PNG, **배경 투명**(맵·벨트처럼 '바탕'이라고 적은 것만 불투명).
- 크기: 아래 크기 또는 그 2배로 그린다. 화면에서 늘이고 줄이므로 비율만 맞으면 된다.
- 그림 방향: [art-direction.md](../../docs/design/art-direction.md)(동화풍, 2~2.5등신, 둥근 선, 파스텔, 남보라 외곽선, 볼터치). 프롬프트는 [PROMPTS.md](PROMPTS.md).
- 우선순위: ★ = 스테이지 1을 해 볼 때 바로 보이는 것. 먼저 넣으면 좋다.
