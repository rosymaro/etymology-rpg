# 지도 배경 그림

큰 지도의 배경 그림이다. 지금 들어 있는 `.webp`는 지도 그리개(`tools/map/paint/`, 동화책 삽화풍)가 그린 것이다.

- 사람이 그린 그림(`.png`)을 같은 자리에 넣으면 그것을 먼저 쓴다.
- 지도 그리개를 다시 돌려도 `.png`는 건드리지 않는다. 설계는 `docs/design/art-direction.md`의 '조각 그림과 그림 파일' 절에 있다.

## 크기와 이름

- **지도 크기:** 260×160칸이고, 한 칸은 64px이다. 전체는 16640×10240px이다.
- **한 장의 크기:** 1024×1536px(16×24칸)이다. 가로 17장, 세로 7장이다.
- **끝 조각:** 지도 끝 조각은 지도가 끝나는 칸까지만 잘라서 더 작다. 칸 중간에서 끊기지 않는다.
  - 오른쪽 열(`16_*`)은 256px 폭이다.
  - 아래 줄(`*_6`)은 1024px 높이이다.
  - 오른쪽 아래(`16_6`)는 256×1024px이다.
- **이름:** `<열>_<행>`이다. 열은 왼쪽부터 0, 행은 위부터 0이다.
- **찾기:** 어느 장이 어디인지는 `overview.png`에 격자와 번호로 나온다. 저장소의 `docs/art/map/`에서 지금 그림(전체와 장마다)을 바로 볼 수 있다.

## 받는 파일

| 파일 | 내용 |
|---|---|
| `<열>_<행>.psd` | 한 장. 아래 겹이 들어 있다 |
| `preview/<열>_<행>.png` | 그 장의 겹을 합친 모습(보기용) |
| `overview.png` | 지도 전체(1/8 크기)와 장 번호 |

PSD 겹(아래부터 이 순서로 겹친다. 겹 이름은 바꾸지 않는다):

| 겹 이름 | 그리는 것 | 바탕 | 게임이 하는 것 |
|---|---|---|---|
| `ground` | 땅, 물 바탕, 바닷가 모래, 길, 다리, 울타리, 절벽, 생울타리 밑, 눈 지역 성벽, 마을 건물 | **불투명** | 없음 |
| `grass` | 풀잎, 꽃, 자갈 | **투명** | 옵션에서 끌 수 있다 |
| (물 움직임) | | | 물결, 반짝임, 물가 거품, 용암 끓음을 이 사이에 그린다 |
| `mtn` (mountains, town wall, castle) | 산, 동굴 입구, 마을 성벽·탑·성문 문루, 성 | **투명** | 없음 |
| `trees` | 숲의 나무, 생울타리 덤불, 말뿌리 나무 | **투명** | 없음 |
| `guide` (숨김) | 참고용: 막힌 칸(옅은 빨강)과 칸 격자 | | 게임에 안 들어간다 |

## 담은 것과 뺀 것

[사용자 의견] 사라지거나 움직이는 것은 빼고, 사라지지 않고 움직이지 않는 지형지물은 담는다.

- **담은 것:**
  - 땅, 물, 산, 숲, 풀·꽃, 길, 다리, 울타리, 절벽, 성벽
  - 마을 건물(공방, 주문판, 병원, 집, 큰 나무)
  - 퀘스트 길목(다리·바위 길)은 **열린 모습**이다.
- **뺀 것(게임이 위에 그린다):**
  - 닫힌 퀘스트 길목(부서진 다리·막힌 바위). 열리면 사라진다.
  - 퍼즐 구멍(돌로 메우면 사라진다)
  - 막힌 문
  - 상자, 퍼즐 돌, 표지판, 보스 문
  - 몹, 마을 사람, 작은 동물, 날리는 꽃잎
  - 이름표·글씨
  - 굴뚝 연기
  - 물결·거품

## 지킬 것

- **다니는 길은 그림이 아니라 칸으로 정해진다.** 물·산·숲·벽은 `data/map/world.json`의 칸으로 정해져 있다. 그림을 새로 그려도 막히는 곳은 그대로다.
  - 그래서 지금 그림과 **같은 자리에 같은 것**(물은 물, 산은 산)을 그린다.
  - 숨긴 `guide` 겹을 켜면 막힌 칸이 보인다.
- **산은 칸 위로 솟는다.** 높은 산은 위로 3칸쯤 솟고, 장 경계를 넘어도 된다. 넘는 부분은 양쪽 장에 똑같이 이어 그린다.
- **이웃 장과 경계가 이어지게 그린다.**
- **투명 겹은 진짜 투명으로 그린다.** 검은 바탕이나 흰 바탕을 쓰지 않는다. 반투명 가장자리는 괜찮다.
- **크기를 바꾸지 않는다.** 파일 이름도 그대로 둔다.

## 넣는 법

1. **지금 그림 내보내기**(이 저장소에서, Godot가 있는 컴퓨터):
   `python3 tools/map/export_map.py ~/map_psd`
2. **고쳐 그리기:** 받은 PSD를 고쳐 그린다. 겹은 지우지 말고 그대로 둔다.
   - 겹을 다 합친 PNG 한 장으로 줘도 된다. 그 장은 바닥 한 장으로만 쓰여 풀·나무가 흔들리지 않는다.
3. **게임에 넣기:** `python3 tools/map/import_map.py ~/map_psd_그린것`
   - 장마다 `assets/map/<겹>/<열>_<행>.png`로 풀린다. 넣지 않은 장은 게임이 계속 코드로 그린다.
   - 일부만 넣으려면 `--only 7_3,8_3`처럼 장 번호를 준다.
4. **커밋하기:** 커밋하면 CI가 APK를 만든다.

필요한 것: Python 3, Pillow, numpy, psd-tools(`pip install psd-tools`)

## 성 안

성 안 지도(30×22칸, 1920×1408px)는 한 장 그림이다: `assets/map/caves/s01_castle.webp`(`tools/map/paint/interior.py`가 그린다). 같은 크기로 그려 같은 이름으로 넣으면 그 그림을 쓴다. 벽·바닥 판정은 `data/map/world.json`의 `cave_maps.s01_castle` 칸 그대로다.
