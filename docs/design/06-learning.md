# 학습 설계: 어원으로 뜻 유추하기

이 게임의 목표는 **어원을 통해 뜻을 유추하는 방법을 게임으로 쉽고 재미있게 알려 주는 것**이다(사용자 의도). 카드 전투는 핵심이라 그대로 두고, 그 둘레(조우, 말 공방, 대장간, 도감, 퀘스트, 이야기)를 이 목표에 맞춘다.

이 문서가 정하는 것: 무엇을 배우는가(1절), 어떤 순서로 도움을 거두는가(2절), 스테이지마다 배울 조각(3절), 장치마다 맡는 일(4절), 재미와 학습의 균형(5절), 이야기(6절), 데이터와 만드는 순서(7·8절).

## 1. 배울 것 세 칸

| 칸 | 할 수 있게 되는 것 | 예 |
|---|---|---|
| ① 조각 알기 | 어원 조각과 뜻을 짝짓는다 | fac = 만들다, de- = 떨어져 |
| ② 조각 찾기 | 처음 보는 단어 안에서 아는 조각을 찾는다 | de**fec**t, ef**fec**t 속의 fac |
| ③ 뜻 유추 | 조각 뜻을 이어 단어 뜻을 짐작하고, 맞았는지 확인한다 | 떨어져 + 만들다 → "결함?" → 풀이로 확인 |

- '조각'은 접두사(de-, com- …)와 어근(facere → fac/fec/fic …)이다. 데이터는 단어의 `etym`(조각 이름, 조각 뜻, 단어 속 모양 `form`)을 쓴다.
- ③의 "맞았는지 알기"는 언제나 **풀이 장면**으로 준다: 단어가 조각으로 갈라지고, 조각 뜻이 이어져 단어 뜻이 되는 짧은 애니메이션(정답이든 오답이든).

## 2. 도움을 거두는 사다리

처음에는 다 보여 주고, 스테이지가 오를수록 하나씩 숨긴다. 플레이어가 하는 일이 ③ → ①③ → ②①③으로 늘어난다.

| 단계 | 스테이지 | 게임이 보여 주는 것 | 플레이어가 하는 것 |
|---|---|---|---|
| A 보여 주기 | 1 | 단어를 조각으로 나눠 색칠, 조각 뜻도 보임 | 이어진 뜻 고르기(③, 거의 공짜) |
| B 조각 뜻 떠올리기 | 2~3 | 조각으로 나눠 주지만 **배운 조각의 뜻은 숨김**(안 배운 조각은 뜻을 보여 줌) | 숨은 조각 뜻 떠올리기(①) → 단어 뜻 고르기(③) |
| C 조각 찾기 | 4~6 | 나누지 않은 단어 | 아는 조각을 눌러 찾기(②) → ① → ③ |
| D 처음 보는 단어 | 7~9 | 배운 조각만으로 된, 아직 잡은 적 없는 단어 | 도움 없이 ②①③. 함정(겉모양만 같은 조각, 뜻이 바뀐 단어)이 나온다 |
| E 혼자 읽기 | 10 | 도움 없음 | 아무도 가르쳐 준 적 없는 단어 읽기 |

- 단계는 스테이지로 정하지만, **조각마다 익숙함**(맞힌 횟수)이 쌓이면 그 조각은 한 단계 앞당겨 숨긴다(잘 아는 것은 빨리 거두고, 모르는 것은 오래 돕는다).
- 막히면 **힌트**로 한 단계 아래 도움을 받는다(코인을 쓴다, 5절).
- 조각으로 나눠 보여 줄 때(A·B, 풀이)도 그 위에 **원래 단어**를 같이 보인다(사용자 의견: 조각만 있으면 원래 단어가 무엇이었는지 모른다).

## 3. 스테이지마다 배울 조각 (3~5개)

[사용자 결정] 한 스테이지에 새 조각은 3~5개. 나머지는 이미 배운 조각을 다시 써서 복습이 되게 한다. 이야기의 '잊힌 뿌리'(00-overview)를 축으로 하고, 그 스테이지 단어에 많이 나오는 접두사를 붙였다. 앞 스테이지 마법(접두사)과도 맞춘다.

| 스테이지 | 새 조각 | 이 조각이 든 그 스테이지 단어 | 배운 조각만으로 된 단어 |
|---|---|---|---|
| 1 공방 마을 | facere(만들다), forma(모양), de-, in-(안에), com- | 22 / 153 | 2 (information, inform) |
| 2 사냥꾼 초원 | capere(잡다), quaerere(찾다), ex-, re- | 31 / 576 | 9 |
| 3 망루 도서관 | videre(보다), legere(고르다·읽다), prae-, pro- | 29 / 601 | 9 |
| 4 바람 협곡 | ire(가다), cedere(가다·물러나다), ad-, sub- | 44 / 623 | 31 |
| 5 항구 도시 | portare(나르다), ferre(나르다), dare(주다), trans- | 70 / 642 | 54 |
| 6 왕성 | dicere(말하다), regere(다스리다), ducere(이끌다), dis- | 67 / 601 | 41 |
| 7 소용돌이 호수 | vertere(돌리다), tornare(돌리다), inter-, ob- | 35 / 533 | 19 |
| 8 성벽 요새 | stare(서다), ligare(묶다), trahere(끌다), un- | 82 / 533 | 56 |
| 9 부서진 광산 | rumpere(깨다), finis(끝), pars(부분) | 43 / 533 | 34 |
| 10 갈라진 탑 | mittere(보내다), tenere(잡다), spectare(보다) | 2 / 533(대부분 복습) | 10 |

- **세어 본 결과와 그에 맞춘 규칙:** 한 스테이지에 조각을 3~5개만 배우면, 배운 조각만으로 된 단어는 스테이지 단어의 1~10%뿐이다(스테이지 1은 2개). 그래서 유추 문제는 **배운 조각이 하나라도 든 단어**(스테이지마다 수십~200여 개)로 낸다. 배운 조각은 숨기고, 안 배운 조각은 뜻을 보여 주는 **반쯤 도움**으로 푼다(2절 B). 조각이 없거나 하나뿐인 단어(스테이지마다 절반 남짓)는 지금처럼 뜻 문제로 내고, 풀이 장면으로 어원을 보여만 준다.
- in-은 두 가지다. 스테이지 1에서 "안에"(inform), 스테이지 8~9에서 "아닌"(invisible)을 함정으로 다시 배운다.
- 표는 `tools/data/build_curriculum.py`(만들 것)가 단어 데이터에서 다시 세어 `data/learning/curriculum.json`에 넣는다. 조각 이름·뜻은 단어장 데이터의 `etym`을 그대로 쓴다(단어장 앱 저장소는 읽기만).

> [의견] 조각을 고르는 기준: 후보 ① 이야기의 잊힌 뿌리 + 그 스테이지에 많은 접두사 ② 순수하게 단어를 가장 많이 덮는 조각(탐욕 선택) ③ 마법 접두사 순서 → ①. ②로 고르면 덮는 단어는 조금 늘지만(스테이지 1: 2 → 6개), mens·munus처럼 이야기와 동떨어진 조각이 먼저 나온다. 이야기가 "fac을 되찾았다"고 말할 때 게임도 fac을 가르쳐야 한다.

## 4. 장치마다 맡는 일 (카드 전투는 그대로)

| 장치 | 바꾸는 것 | 맡는 칸 |
|---|---|---|
| **조우 퀴즈 → 유추 퀴즈** [사용자 동의] | 필드 몹과 부딪히면 나오는 퀴즈를 2절 사다리대로 바꾼다. 배운 조각이 든 단어면 유추 문제(단계별 도움), 아니면 뜻 문제. 고른 뒤 풀이 장면. 다 맞히면 지금처럼 전투 없이 잡고, 틀리면 전투 | ①②③ |
| **카드 전투: 약점 찌르기** [사용자 동의] | 전투 규칙에 하나만 더한다. 턴 앞에서 적 카드 단어 속 **배운 조각**을 눌러 맞히면 그 턴 공격이 세진다(수치는 `battle_magic.json`처럼 `data/balance/`에). 틀린 곳을 누르면 아무 일 없음. 한 적에 한 번. 조각을 찾는 눈이 곧 전투 실력이 된다 | ② |
| **동료 유닛** | 새 조각(어근)을 배우는 순간을 '동료가 그 힘을 되찾는' 장면으로 보여 준다(지금의 새 어근 기쁨 화면을 조각 배우기로 넓힌다) | ① |
| **전투 마법(접두사)** | 마법을 얻을 때 접두사 뜻을 함께 배운다. 방어 마법의 조합 뜻 고르기는 그대로(③) | ①③ |
| **말 공방** | 칠판의 도움을 사다리대로 줄인다: 1~3번 게임은 `어원+어원=단어→뜻` 모두, 4~6번은 뜻만 보고 조각 조립, 7번부터는 처음 보는 단어 | ①② |
| **대장간 진화** | 진화한 단어는 재료 단어의 조각 조합인 경우가 많다. 재료 뜻 맞히기에 더해, 진화 단어의 뜻을 조각으로 유추하게 한다 | ③ |
| **도감 → 조각 나무** | 단어 목록 옆에 조각마다 '가족'(그 조각이 든 단어들)을 나무로 보여 준다. 가족을 채우는 것이 수집 재미 | ① |
| **퀘스트** | 스테이지마다 '처음 보는 표지판 단어를 읽어 길을 연다' 같은 유추 퀘스트 하나 | ③ |
| **칭호 시험** | 그대로(04-meta 5절). 문제에 유추 문제를 섞는 것은 나중에 | – |

## 5. 재미와 학습의 균형

- **틀려도 아프지 않다:** 유추를 틀리면 전투를 할 뿐이고(지금 구조), 풀이 장면은 꼭 본다. 틀린 조각은 '다시 볼 조각'에 오른다.
- **맞히는 기쁨을 크게:** "처음 보는 단어를 조각으로 맞혔다!"를 따로 축하한다(배운 조각만으로 된 처음 보는 단어를 도움 없이 맞혔을 때). 이 게임의 핵심 감정이다.
- **스스로 고르는 난이도:** 도움 없이 맞히면 경험치를 더 준다. 막히면 코인으로 힌트(한 단계 아래 도움)를 산다. 수치는 `data/balance/learning.json`.
- **복습:** 틀린 조각이 든 단어가 필드에 더 자주 나온다(지금의 '다시 잡기'를 조각 단위로 넓힌다). 스테이지 몹은 배운 조각이 든 단어를 절반쯤 섞어 낸다.
- **한 번에 하나:** 한 문제에서 새로 묻는 것은 하나뿐. 처음 보는 조각을 두 개 이상 숨기지 않는다.

## 6. 이야기를 사다리에 맞추기

사용자 의도에 맞춰 이야기의 뜻을 조금 바꾼다. 큰 줄기(devil, 10스테이지, 영차의 배신)는 그대로 둔다.

- **잃은 것은 뜻이 아니라 '읽는 법':** devil이 뿌리를 자르자 사람들은 단어를 쪼개 보는 눈을 잃었다. 주인공은 그 눈을 되찾아 가는 사람이다. 뿌리를 되찾는 것 = 조각을 배우는 것.
- **뚝딱이 물러난다:** 스테이지 1에서는 뚝딱이 단어를 다 풀어 준다(지금의 `_etym` 대사, 단계 A). 2~3에서는 "이 조각 뜻 기억나?"라고 묻고, 4~6에서는 "조각은 네가 찾아 봐", 7~9에서는 "힌트만 줄게". 10에서는 devil에게 붙잡혀 곁에 없다. 사다리가 이야기 속 사건이 된다.
- **devil의 무기는 가짜 어원:** 보스들이 겉모양만 같은 조각(예: 어원이 다른 in-, 뜻이 바뀐 단어)으로 사람들을 속인다. 단계 D의 함정 학습과 겹친다.
- **마지막:** 뚝딱 없이, 아무도 가르쳐 준 적 없는 단어를 주인공이 혼자 읽어 내며 끝난다. 최종전에서 마을 사람들이 외치는 단어도 그들이 스스로 읽어 낸 단어다.
- **스테이지 1 새 흐름(예):** defect(풀어 줌) → information(풀어 줌, 알림판) → 들판에서 fac·form이 든 단어를 유추 → 척척 합류 → 알림판 단어를 유추로 읽어 퀘스트 → 다리·절벽 → destroyer(de- + struere: 아래로 + 쌓다 → 무너뜨리다, 이 조각 풀이가 보스 공략의 열쇠).
- 장면·대사는 이 문서를 받아들인 뒤 스테이지마다 고친다(`data/scenes/*.json`, `locale/story.csv`, render·storyboard 다시 만들기).

## 7. 데이터와 규칙 층

| 것 | 자리 | 내용 |
|---|---|---|
| 커리큘럼 | `data/learning/curriculum.json` | 스테이지마다 새 조각 id, 조각 뜻, 단어 속 모양들. 스크립트가 만든다 |
| 학습 수치 | `data/balance/learning.json` | 단계 경계, 익숙함 기준(몇 번 맞히면 앞당겨 숨김), 힌트 값, 보상 배수, 약점 찌르기 세기 |
| 조각 익숙함 | `GameState.pieces` | 조각 id → {seen, right}. 저장한다 |
| 유추 문제 화면 | `src/ui/quiz_screen.gd`(조우) | 나눠 보여 줄 때는 조각 칩(위: 조각, 아래: 뜻 또는 ?), 고른 뒤 풀이 "in(안에) + form(모양) + ation → 정보" |
| 유추 문제 만들기 | `src/domain/learning/inference_quiz.gd` | 단어 + 배운 조각 + 단계 → 보여 줄 것/숨길 것, 보기 4개, 풀이. 노드를 모른다. 단위 테스트 |
| 조각 찾기 판정 | `src/domain/learning/piece_finder.gd` | 단어 글자에서 조각 자리(`form`의 위치) 찾기, 누른 자리가 맞는지 |

## 8. 만드는 순서

1. ✔ 커리큘럼 스크립트와 데이터(3절 표를 데이터로) + 규칙 층(유추 문제, 조각 찾기) + 테스트 — `tools/data/build_curriculum.py`, `src/domain/learning/`
2. ✔ 조우 퀴즈를 유추 퀴즈로(단계 A~C) + 풀이 장면 — 단계 C의 '조각을 눌러 찾기'는 3번(약점 찌르기)과 같은 조각 찾기 화면으로 함께 만든다
3. 약점 찌르기(전투)
4. 이야기: 스테이지 1 장면·대사를 6절대로, 뚝딱의 물러남
5. 말 공방 칠판 도움 줄이기, 대장간 유추, 도감 조각 나무, 유추 퀘스트
6. 단계 D·E(처음 보는 단어, 함정)는 스테이지 7 이후를 만들 때

## 정하지 않은 것

- 약점 찌르기의 세기(공격 +몇, 또는 배수)는 시뮬레이션(`tools/balance`)으로 정한다.
- 힌트 값(코인)과 도움 없이 맞힌 보상 배수.
- 익숙함 기준(같은 조각을 몇 번 맞히면 한 단계 앞당길지). 처음엔 3번.
