# 미니게임 10개 (구현 1차)

규칙의 바탕은 [01-rpg-base.md](01-rpg-base.md) '미니게임 규칙 1차'. 이 문서는 코드로 옮기며 정한 것과 가정이다.
목록은 `data/minigames.json`(고정), 수치는 `data/balance/minigames.json`(레벨 테스트로 고침), 규칙 코드는 `src/domain/minigame/`, 화면은 `src/ui/minigames/`.

## 공통

- 한 판 최대 5개(`max_words`). 시간 제한이 있는 게임은 `duration`초.
- 쓰는 단어: 그 마을(스테이지)에 배정된 마을 단어 중 **아직 못 얻은 것**부터 `pool_size`(16)개. 모자라면 얻은 것, 그래도 모자라면 그 스테이지 필드 단어를 섞는다.
- **스토리**: 판이 끝나면 얻은 단어마다 뜻 4지선다. 맞힌 것만 갖는다(01-rpg-base '단어 시험'). 스테이지 1에서는 마을의 '주문 제작소'에서 한다(전에 있던 게시판 퀴즈를 대신한다).
- **미니게임 메뉴**(처음 화면): 보상 없이 10개를 바로 해 본다. 판이 끝나면 얻을 수 있었던 단어와 뜻만 보여 준다.

## 게임별로 정한 것

| 게임 | 정한 것(가정) |
|---|---|
| 1 주문 제작 | 주문서 = 뜻 + 주속성 무늬. 카드 4장이 2.2초마다 한 칸씩 흐르고, 답 카드는 늘 벨트에 있다. 주문 8개, 주문마다 16초, 3번 틀리면 끝 |
| 2 덫 놓기 | 6×8 칸에 단어 5개. '살피기'와 '덫 놓기'를 버튼으로 바꾼다. 첫 살피기는 늘 안전(그 주변에는 숨기지 않는다). 단어 칸을 살피면 단어가 달아나 끝, 빈 칸에 덫을 놓아도 끝 |
| 3 책 읽기 | 10×10 격자, 영어 글자만 있는 3~9글자 단어 5개. 8방향, 거꾸로 그어도 된다. 힌트는 뜻과 글자 수 |
| 4 연날리기 | 5×6 타일. 왼쪽 연에서 오른쪽 하늘까지 이어지는 정답 길을 먼저 만들고 타일을 무작위로 돌려 둔다(늘 풀 수 있다). 이어지는 순간 길 위의 단어를 모두 얻고 끝 |
| 5 낚시 | 7×7, 물고기 5종, 바꾸기 20번. 터뜨린 물고기 15마리마다 1개. 줄이 안 생기는 바꾸기는 되돌리고 횟수도 안 쓴다 |
| 6 필사 | 3~10글자 단어 5개. 힌트는 뜻과 어원. 2번 틀리면 정답을 보여 주고 다음 단어 |
| 7 물레방아 | 고리 하나에 6칸, 수문 3곳(0·2·4번 칸). 안쪽 고리의 수문 자리에는 맞는 뜻, 나머지는 다른 단어의 뜻이라 맞는 돌림은 하나뿐이다. 다 맞으면 바퀴가 돌고 1개, 5바퀴까지. 화면은 고리를 펼친 세로 줄로 보여 준다 |
| 8 보초 서기 | 무늬 = 단어의 주속성 5종, 통에 4패씩 + 빈 통 2개. 다 맞춘 통마다 그 무늬에 걸린 단어 1개. 판은 '되감기 섞기'로 만들어 늘 풀 수 있다 |
| 9 광석 캐기 | 60초. 광맥 무늬(목표 속성) 광석이 55%, 나머지는 돌. 연속 5개마다 1개, 돌을 깨면 연속이 0 |
| 10 문양 잇기 | 5×5, 쌍 5개(선 길이 3칸 이상). 모든 칸을 지나는 한 줄을 무작위로 만들고 잘라서 판을 만든다(늘 풀 수 있다). 다 채우면 끝, '그만하기'를 누르면 이은 선만큼 얻는다 |

> [의견] 덫 놓기의 '빈 칸을 건드리면 끝'은 후보 ① 빈 칸을 살피면 끝(보통 지뢰찾기와 반대라 헷갈림) ② 빈 칸에 덫을 놓으면 끝 ③ 끝나지 않고 감점 → ②. 지뢰찾기처럼 살피며 숫자를 읽고, 확신할 때 덫을 놓게 한다. 단어 칸을 살피면 단어가 달아나는 것도 끝으로 했다.

> [의견] 보초 서기 패에는 단어 대신 속성 무늬를 적었다. 후보 ① 단어 + 무늬 ② 무늬만 ③ 어근 계열 → ②. 같은 무늬 단어 4개를 마을 단어만으로 다섯 묶음 모으기 어려워서, 무늬로 정렬하고 다 맞춘 통에 보상 단어를 건다. 단어 학습은 판 뒤의 뜻 문제가 맡는다.
