# 10스테이지 전투 시뮬레이션

12지역 때 만든 전투 엔진(`tools/balance/engine.py`)에 2차 설계의 성장(진화·장비·경험치)과 `data/balance/`의 값을 얹어 다시 돌렸다. 다시 돌리는 방법은 [tools/balance/README.md](../../tools/balance/README.md)에 있다.

## 1. 가정

| 항목 | 가정 |
|---|---|
| 플레이어 단어 | 스테이지 s에 들어올 때 앞 스테이지 1차 단어를 모두 가짐. 보스전 때는 그 스테이지 1차의 60%를 더 가짐 |
| 진화 | 재료가 다 모이면 바로 진화(부지런한 플레이어). 비교로 진화를 안 하는 플레이어도 돌림 |
| 경험치 | 최고 레벨은 마지막 보스전 때 평균 56(60까지 여유). 1차 = 스테이지 × 10, 진화 = 재료 최대 스테이지 × 4 × 차수. 모두 받고 입는 유닛은 2배. 누적 200 × L² |
| 파티 | 합류한 유닛 중 무작위(스테이지 1은 2명, 2는 3명, 3부터 4명). 스테이지 9부터 나르기·주기 이탈 |
| 장비 | 유닛·부위마다 가장 높은 차수를 입음. 수치는 `data/balance/gear.json` |
| 속성 능력 | 능력치로 바꿀 수 있는 것만 넣음(생명·영혼·창조 체력, 원소·형상 공격, 일상 방어). 나머지는 0(보수적) |
| 마법 | 그 스테이지까지 얻은 전투 마법 하나. 방어 마법 퀴즈 성공률 80% |
| 필드 적 | `enemy.json` 기준 레벨 + 빈도 보정, 코인은 곡선 값, 그 스테이지 필드 단어의 빈도 분포를 씀 |
| 적 장비 몫 | 적에게 같은 스테이지 부지런한 플레이어 평균 장비 능력치 × `gear_bonus_ratio`(1.0)을 더함 |
| 보스 | 보스전 때 플레이어 평균 레벨 + `level_delta`, 졸개는 필드 기준 + 2 레벨(2~3차) |
| 마지막 전투 | devil + 영차(나르기·주기, 플레이어와 같은 장비) + 다른 보스 2명(레벨 −2) |

## 2. 처음 돌렸을 때 알게 된 것

1. **엔진에서 레벨은 약하고, 코인과 장비가 세다.** 레벨 50 적이 공 6, 방 1, 체 17이다. 장비 첫 가정(1/2/4/6, 머리 방어 + 값)을 넣으면 레벨 4 유닛이 방어 5가 되어 2스테이지부터 모든 전투를 95% 넘게 이긴다. 장비를 4분의 1로 줄여도 그렇다.
2. 그래서 두 가지를 바꿨다.
   - **장비 수치를 낮췄다**(`gear.json`): 무기 공 + v/2, 장갑 공 + v/4, 가슴 체 + v, 신발 체 + v/2, 방어는 4차 머리만 +1.
   - **적도 장비 몫을 갖는다**(`enemy.json` `gear_bonus_ratio`). 적 단어도 그 스테이지 수준의 힘을 갖는다고 본다. 장비 수치를 바꾸면 적도 같이 따라와서 고치기 쉽다.
3. 코인 1개 차이가 레벨 10 차이보다 크다. 그래서 코인은 고르게 오르는 곡선 [1,1,1,2,2,2,3,3,3,4]로 고정하고 레벨로 맞췄다.

진화를 안 하면 레벨이 70% 정도에 머물고 장비가 1차뿐이라 3스테이지부터 거의 이길 수 없다. 적의 장비 몫을 부지런한 플레이어에 맞췄기 때문이다.

> [의견] 후보 ① 지금처럼 둔다(진화가 사실상 필수, 마을에서 진화하도록 강하게 이끈다) ② 적 장비 몫 비율을 0.5로 낮추고 레벨로 다시 맞춘다(진화 안 해도 조금 어렵게 진행 가능) ③ 진화를 안 한 플레이어를 위해 스테이지 입구에 '진화 권유' 안내를 두고 ①을 유지. → 결정이 필요하다. 학습 게임이라 진화 퀴즈(복습)를 꼭 거치게 하려면 ①·③, 자유도를 원하면 ②.

### 넣지 않은 것

- 속성 능력 중 전투 흐름을 바꾸는 것(파동·시간·질서 등)과 적의 속성 능력·팀 묶음. 게임 코드의 규칙 층이 생기면 시뮬레이터가 그 코드를 그대로 쓰게 바꾼다([architecture.md](../dev/architecture.md) 10절).
- 유닛 고르기. 무작위 4명이라 플레이어가 상성을 맞추면 승률은 더 오른다.
- 보스 능력은 12지역 엔진 것을 이름만 맞춰 썼다(destroyer→defect, hurricane→storm, dictator→dictate).
