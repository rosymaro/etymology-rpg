# 그림 방향: 동화풍, 귀엽게

게임 전체 그림은 그림책(동화)처럼 따뜻하고 귀여운 스타일이다. 코믹한 이야기와 학습 게임의 분위기에 맞춘다.

## 원칙

| 항목 | 방향 |
|---|---|
| 형태 | 모서리 없이 둥근 실루엣. 직선보다 부드러운 곡선 |
| 인물 비율 | 2~2.5등신. 머리가 크고 몸이 작다. 눈은 크고 단순(점이나 작은 타원), 볼에 연한 볼터치 |
| 유닛 | 펭귄·병아리 외모. 계열마다 한 가지 대표 색과 소품 하나(망치, 망원경, 방패 …)로 구별 |
| 보스 | 무섭기보다 허당스럽게. 덩치는 크지만 표정이 과장되고, 몸 어딘가에 갈라진 문양 |
| 선 | 짙은 남보라 계열의 부드러운 외곽선. 굵기는 일정하고 끝이 둥글다. 검정 선은 쓰지 않는다 |
| 색 | 채도를 한 단계 낮춘 파스텔. 하늘색·연두·살구·연분홍이 바탕, 주황(마커색)은 효과와 강조에만 |
| 질감 | 수채 번짐 같은 부드러운 면 채색, 옅은 종이 결. 그라데이션은 넓고 은은하게 |
| 배경 | 그림책 삽화처럼 단순한 덩어리. 맵 타일도 손으로 그린 느낌(풀 한 포기, 꽃 점) |
| 어원 잃은 것 | 회색으로 바래고 채도가 빠진다. 되찾으면 색이 번지며 돌아온다(이야기의 '색 복원' 연출) |
| UI | 둥근 모서리 카드, 종이 같은 바탕, 리본·책갈피 모양 라벨. 버튼은 통통한 알약 모양 |
| 글꼴 | 둥근 고딕(본문), 손글씨풍(대사 이름·제목). 다국어 대체 글꼴을 함께 둔다([i18n.md](../i18n.md)) |

## 단어 카드

도감, 파티 장비 고르기, 대장간 진화, 결과 화면, 미니게임 결과처럼 단어가 하나씩 나오는 곳은 모두 같은 단어 카드(`src/ui/word_card.gd`)를 쓴다.

| 알리는 것 | 표시 |
|---|---|
| 속성 | 카드 바탕이 속성 색이다. 속성이 2개면 가운데 대각선을 경계로 둘로 나누고, 3개면 대각선 세 띠로 나눈다(프랑스 국기처럼). 경계는 그라데이션으로 번진다. 색 표는 미니게임과 같다(`MinigameScreen.ATTR_COLORS`) |
| 착용 부위 | 단어 앞 아이콘: 무기(검), 머리(투구), 가슴(갑옷), 장갑, 신발(장화). 부위가 없는 단어(보스 단어)는 아이콘이 없다. 그림 `slot/<부위>.png`가 있으면 그것을 쓴다 |
| 이미 가졌는지 | 단어 글자색. 가진 단어는 남보라, 처음 보는 단어는 진한 주황. 퀴즈의 큰 단어와 전투의 적 이름도 같은 색 규칙을 따른다 |

&#91;의견\] 처음 보는 단어 표시 후보 ① 글자색 ② 'NEW' 딱지 ③ 테두리 색 → ①(사용자 지정). 주황은 원래 강조색이라 눈에 잘 띈다. 대신 바탕 속성 색과 겹치지 않도록 진하게 했다.

## 하지 않는 것

- 실사풍 그림자, 날카로운 금속 질감, 피·상처 표현
- 원색 대비가 강한 배색, 검정 바탕 위주의 어두운 화면(밤 장면도 남색 계열로)
- 특정 게임의 캐릭터·그림체를 따라 그리기

## 스토리보드와의 관계

스토리보드의 콘티는 이 방향을 따라 둥근 선과 파스텔 색, 볼터치로 그렸다. 하지만 콘티는 장면 구성을 보는 개략 그림이고, 실제 아트는 이 문서를 기준으로 따로 만든다.
