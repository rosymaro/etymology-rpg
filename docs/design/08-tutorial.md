# 튜토리얼: 처음 하는 것마다

사용자 의견: 처음 하는 것들은 충분한 튜토리얼을 만든다. 무엇을 골라야 하는지 **화살표**로 가리키고, 그곳만 밝게 **포커스**하고 그 바깥은 **반투명한 어두운 색**으로 덮는다. 대사·설명으로 전달한다. 필드, 미니게임(처음 하는 것마다), 전투(처음), 유닛 스킬 장착에 넣는다.

## 1. 모양

- **어둡게 덮기:** 화면 전체를 **반투명한 밝은 회색**(회색 45%쯤, 사용자 의견: 너무 어두우면 글씨가 안 보인다)으로 덮고, 가리킬 자리(버튼·카드·지도 위 한 곳)만 둥근 사각형으로 뚫어 밝게 둔다. 뚫린 자리 둘레에 밝은 테두리가 천천히 숨 쉬듯 커졌다 작아진다.
- **화살표:** 뚫린 자리를 가리키는 큰 화살표가 그 자리 쪽으로 통통 움직인다. 자리가 화면 위쪽이면 아래에서, 아래쪽이면 위에서 가리킨다.
- **글씨는 밝게:** 반투명한 칸·바탕 위의 글씨는 흰색이나 밝은 색으로 쓴다(사용자 의견). 필드 알림(토스트)도 반투명 회색 바탕에 흰 글씨.
- **말풍선:** 뚝딱(또는 그 장면의 인물)의 얼굴과 말풍선. 화살표 반대쪽에 둔다. 대사는 `locale/tutorial.csv`.
- **넘어가기:** 단계마다 두 가지 중 하나.
  - **눌러서:** 뚫린 자리를 눌러야 넘어간다(그 버튼이 진짜로 눌린다). 다른 곳을 누르면 아무 일 없이 화살표만 한 번 튄다.
  - **읽고:** 설명만 하는 단계는 화면 아무 곳이나 누르면 다음.
- **건너뛰기:** 오른쪽 위 작은 '건너뛰기'. 한 번 본(또는 건너뛴) 튜토리얼은 다시 나오지 않는다(`state.flags["tut_<id>"]`). 옵션 화면에서 '튜토리얼 다시 보기'로 모두 되살린다.

## 2. 무엇을 언제

| id | 언제(처음) | 단계 |
|---|---|---|
| field | 처음 필드에 나갈 때(공방 마을 첫 장면 뒤) | 화면 어디나 끌면 움직임 → 미니맵(누르면 전체 지도) → '할 일' → 퀘스트 버튼 → 몹과 부딪히면 퀴즈 → '마을로' |
| field_magic | 필드 마법 버튼이 처음 보일 때 | 버튼 가리키기 → "de-: 둘레 몹을 멈춰요. 절벽 앞에서는 내려가요" |
| hunt | 처음 마을 밖으로 나설 때 | 망치가 저절로 날아감(사냥 칸 가리키기) → 구슬과 주머니 → 마을에 들어가야 내 것 |
| level_up | 처음 사냥 레벨이 오를 때 | 보기 3개 가리키기 → 하나 고르기 |
| quiz | 처음 조우 퀴즈 | 조각 칩 가리키기("in = 안에, form = 모양") → 풀이 → 보기 하나 누르기 |
| battle_prep | 처음 전투 준비 | 출전 유닛 → 적 → 장착 어근 → '전투 시작' |
| battle | 처음 전투 | 두 카드(공격·방어·체력) → 코인(앞면이면 능력치가 오름) → '다음' → 마법 칸(있으면) → 빨리 보기 |
| party | 처음 유닛 창(또는 처음 어근을 2개 이상 갖게 됐을 때) | 유닛 카드의 '어근' 버튼 가리키기 → 누르기 → 어근 하나 고르기 → "전투에서 이 어근의 스킬을 써요" → 필드 마법·덱 칸 |
| minigame_f01 … f10 | 미니게임마다 처음 | 그 게임에서 새로 생긴 영역·기능을 차례로 가리킨다(아래 표) |
| puzzle | 처음 퍼즐 구역에 들어갈 때 | 돌 가리키기 → "돌에 붙어 밀어 봐요" → 발판·상자 |
| lock | 처음 조각 자물쇠 | 그림 단서 → 쪽지 조각 → 차례로 누르기 |
| cave | 처음 동굴에 들어갈 때 | "어두워요. pro-로 밝히고 ex-로 나와요" |
| gacha | 처음 말 뽑기 | 코인 → 1번 뽑기 |
| hospital | 처음 병원(이미 장면이 있다) | 남은 시간 칸 가리키기 |

### 미니게임마다(05-minigames)

| 게임 | 가리킬 것 |
|---|---|
| f01 | 칠판 → 벨트의 어원 조각 → 용광로에 넣기 → 두드리기 → 함정 어원 |
| f02 | 에너그램 영역 → 섞인 글자 누르기 → 글자 순서를 틀리면 1번 틀림 |
| f03 | 단어 뜻 영역 → 쌓인 단어 → 진열대 칸으로 끌기 |
| f04 | 흡수(0/5) → 달아오른 용광로 → 단어찾기 → 끌어서 찾기 |
| f05 | 영역 사이 옮기기(◀ ▶) → SKIP → 쓰레기통 |
| f06 | 두드려 만든 단어가 단어 뜻 영역으로 |
| f07 | 손으로 용광로에 넣기, 필요 없는 어원을 넣으면 1번 틀림 |
| f08·f09 | 용광로 흡수 수가 늘었다(7개·10개) |
| f10 | 단어찾기에서 거꾸로 숨은 단어 |

## 3. 만드는 법

- **`TutorialOverlay`(화면):** 단계 목록을 받아 차례로 보여 준다. 단계 = {target: 가리킬 컨트롤 또는 화면 좌표 사각형, text: 대사 키, speaker, mode: tap_target | tap_any}. 어둡게 덮기는 뚫린 사각형 바깥 네 조각으로 그린다(눌림도 바깥에서만 막는다).
- **`TutorialBook`(규칙):** 어떤 튜토리얼을 보였는지(`flags`), 다음에 보일 것. 화면은 "이 화면에 처음 왔다"를 알리고, 책이 보일지 정한다. 노드를 모른다. 단위 테스트.
- 각 화면은 가리킬 컨트롤을 이름으로 내놓는다(`tutorial_target(name) -> Control`). 지도 위 한 곳(돌·상자)은 화면 좌표 사각형으로.
- 테스트: 처음에만 보이는지, 건너뛰면 다시 안 나오는지, 눌러서 넘어가는 단계에서 바깥을 눌러도 안 넘어가는지.

## 4. 만드는 순서

1. ✔ TutorialOverlay·TutorialBook + 필드(field: 움직이기·미니맵·할 일·마을로·파티·필드 마법·퀘스트, hunt, level_up) + 조우 퀴즈 + 전투 준비·전투(마법 칸 포함) + 유닛 창(장착 칸 → 어근 버튼 → 어근 고르기)
2. ✔ 미니게임 f01~f10(칠판 → 벨트 → 작업대 → 옆 영역 버튼, 게임마다 대사)
3. ✔ 퍼즐·자물쇠·동굴·뽑기. 병원은 이미 장면이 있어 따로 두지 않았다
- 옵션 '튜토리얼 다시 보기'. 테스트·화면 캡처에서는 튜토리얼을 끈다(`GameData.tutorials_enabled`), 튜토리얼 테스트(`tests/smoke/test_tutorial.gd`)만 켠다
